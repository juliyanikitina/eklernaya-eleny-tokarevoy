# Эклерная Елены Токаревой

**[Открыть сайт](https://juliyanikitina.github.io/eklernaya-eleny-tokarevoy/)**

Светлая интерактивная витрина корпусных десертов: малина, фисташка, ежевика, голубика, лимон и манго.

Все шесть вкусов представлены короткими видеороликами: вилка раскрывает оболочку и поднимает кусочек начинки. Карточки отмечены подписью «Живое раскрытие».

Кнопка «Музыка Франции» включает инструментальный вальс, созданный для этой витрины. Доступны регулировка громкости и выключение. При открытии страницы звук выключен.

Ориентиры подачи изучены в Instagram [@eklernaya22](https://www.instagram.com/eklernaya22/): светлая упаковка, красные акценты и рукописные заголовки. Палитра сайта — их интерпретация для пробной витрины; официальный брендбук не предоставлен.

## Ветки

- `main` — сохранённая базовая версия.
- `site-presentation` — рабочая ветка сайта и источник публикации GitHub Pages.

## Локальный запуск

`python -m http.server 4173 --bind 127.0.0.1`

Открыть http://127.0.0.1:4173/.

## Материалы

Изображения — художественная подача по исходным фотографиям десертов. Состав и оформление требуют подтверждения перед коммерческим использованием. Цены, контакты и возможность оформить заказ в тестовой версии не заданы.

Нет зависимостей, внешней аналитики или форм сбора данных. Видео включается без звука, поддерживает паузу и reduced motion.
